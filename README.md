# HeyDoc Assets (`heydoc-assets`)

Central repository for HeyDoc brand assets, UI presets, diagrams, logos, and journey flows.

## 📁 Repository Structure

```text
├── HeyDoc Logo.png                       # Primary HeyDoc Brand Logo
├── hero/                                 # Hero section visuals and agents
├── presets/
│   ├── architecture_flow_presets/        # System & architecture flow diagrams
│   ├── comparison_ecosystem_presets/     # Ecosystem comparison graphics
│   ├── consumer_experience/              # Consumer journey & chat interaction mockups
│   ├── core_capabilities/                # Feature & core capability showcases
│   ├── dynamic_presets/                  # Dynamic workflow cards
│   ├── enterprise_presets/               # Enterprise dashboard and workflows
│   ├── features/                         # Feature highlights & integrations
│   ├── logo_presets/                     # Partner, integration, and client logos
│   ├── metric_cards/                     # KPI, performance, and metric UI cards
│   ├── mobile_mockup/                    # Mobile device screens & mockups
│   ├── modular_ui_mockups/               # Modular timeline & memory components
│   ├── multi_feature_showcase/           # Ecosystem & multi-feature diagrams
│   ├── patient_journey_steps/            # Step-by-step patient care journey
│   └── platform_showcase/                # Agent orchestration and omnichannel hubs
├── manifest.json                         # Machine-readable asset catalog with tags & metadata
└── README.md
```

## 🤖 Structured Manifest for AI Agents & Automation

This repository includes [`manifest.json`](manifest.json) containing structured metadata for all assets:
- **Asset Names & Relative Paths**
- **Categories & Subcategories**
- **Extracted Tags**
- **Usage Rules & Formats**

AI agents and automated pipelines can query [`manifest.json`](manifest.json) directly to locate the exact visual assets needed for UI components, docs, or presentations.

## 📌 Usage Guidelines

- Always maintain the original aspect ratio when embedding or resizing assets.
- Do not modify, skew, or recolor official brand marks or partner logos.
