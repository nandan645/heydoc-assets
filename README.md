# HeyDoc Assets (`heydoc-assets`)

Central repository for HeyDoc brand assets, UI presets, diagrams, logos, deck graphics, and journey flows.

## 📁 Repository Overview

Assets are organized into directory categories:

- **Brand Assets**: Core logos and marks (e.g., `HeyDoc Logo.png`)
- **`hero/`**: Hero section visuals, promotional graphics, and hero agent assets
- **`deck/`**: Presentation deck graphics, partner/institutional logos, UI previews, and illustrations
- **`presets/`**: UI components, flows, mockups, capability cards, and diagrams
- **`manifest.json`**: Machine-readable metadata catalog (when present)

Assets can be referenced directly via repository relative paths or raw GitHub CDN URLs.

## 📌 Usage Guidelines

- Always maintain the original aspect ratio when embedding or resizing assets.
- Do not modify, skew, or recolor official brand marks or partner logos.
- Prefer vector (`.svg`) formats for logos/icons where available, and high-resolution raster (`.png`) for mockups.
